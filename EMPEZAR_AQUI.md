# Empezar aquí

1. Abre `index.html` (o `npm run serve` → `http://localhost:8000/`) para **jugar**.
2. Lee `PLAN.md` (qué hay y qué viene), `CONTEXTO_CODEX.md` (cómo está hecho) y `AGENTS.md` (convenciones).
3. Para jugar en remoto o en el móvil de un amigo, sigue `PUBLICAR.md`.
4. `npm test` ejecuta las pruebas (Node 18 o posterior; sin `npm install`).
5. `fighter-preview.html` es el Fighter Lab para inspeccionar animaciones, cajas y capas; se regenera con `python3 tools/build_demo.py`.

`references/` contiene las fotos del usuario (excluidas de git) y `source-art/` los originales gráficos usados para empaquetar los sprites.
